# Repeatable adversarial checks

Generated by `scripts/review/` from preserved source files. These scripts do not
import production geometry/interpolation. They were authored by the same
assistant, so computational separation is not independent human review.

| Product | Scope |
|---|---|
| `independent_decoder.json`, `independent_rays.csv` | Review Message-31 byte walker versus installed Py-ART; every native REF/VEL/SW code and descriptor |
| `custom_independent_comparison.json` | Preserved custom parser versus review walker; ray/SW omissions and shared codes |
| `geodesic_check.csv`, `beam_geometry_check.csv`, `geometry_summary.json` | Separate Vincenty and effective-radius equations versus production geometry |
| `all_ray_sensitivity.csv` | 55 fully reselected all-ray cases, including eight combined clock/altitude/refraction cases |
| `target_sensitivity.csv`, `sensitivity_overlap_examples.csv` | Target geometry and example moment samples under each declared assumption |
| `clock_independent_check.csv` | Per-ray flags compared with production for all five ±2-second clock cases |
| `clock_candidates_not_in_pr_scenarios.csv` | Missing candidates in the production clock coverage; header-only means none |
| `perimeter_audit.json`, `perimeter_point_distances.csv` | Distance to a sourced proposed circle, not an operative TFR or property perimeter |
| `flight_evidence_check.json`, `reported_descent_observations.csv` | Provider-reported late altitude sequence; not independently verified aircraft descent |

`legacy_fixed_slant_rectangular_*` columns deliberately preserve the rejected
prior approximation for comparison. `circular_*` columns use the 3D cone and
aircraft-point native gates. Projection flags are not joint overlap tests.
Scenario magnitudes are diagnostic assumptions, not measured uncertainty,
probability distributions or exhaustive envelopes. Positive shift queries later
FR24 timestamps. Missing brackets are excluded, never extrapolated.

The byte walker handles only these BZip2-compressed KAMX Message-31 archives. It
skips ancillary messages, including type 32, and accepts a final 12-byte framing
advance after checking referenced moment bounds, as in Py-ART. It is not a
fully independent framing oracle or general conformance validator. It does not
authenticate source acquisition, calibration or meteorological truth.

The FAA reference PDF and receipt hash are in `docs/reference_sources/`. Its
status is **proposed rule**, not evidence of effective restrictions on the event
date. Original evidence manifests remain separate and unchanged.
